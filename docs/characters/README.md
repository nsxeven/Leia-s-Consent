# Character files (DRAFT v0.1 for darryn's review, 2026-11-08)

One file per character. Every scene writer (human or model) reads the file of
each character in the scene **before** writing a line, and
`docs/DIALOGUE_STYLE.md` before handing anything in.

Why these exist: an F95 player (desmosome, Nov 8) said the dialogue reads like
an AI chatbot: everybody talks in the same clipped, too-cool rhythm and always
has a witty comeback. The numbers agree: in the Prologue + Day 1, 55% of all
spoken lines are four words or fewer, and Leia, Ryan, Julian and Maya all
average 4.2-4.8 words a line. Four different people currently sound like one.

`[girlfriend_name]`, `[friend_name]` (a test enforces it). These docs use the
default names so they're readable.

## How each file is laid out

1. **Snapshot**: who they are in one paragraph.
2. **Wants / fears**: what drives them in a scene.
3. **How they talk**: rhythm, vocabulary, habits, humor.
4. **Under pressure**: how the voice changes when nervous, flirting, jealous, drunk, aroused, hurt.
5. **With each person**: how they talk to the others.
6. **By route**: how they shift on Love, Love + Exhibitionism, NTS, NTR.
7. **Says / never says**.
8. **Sample lines**: drafts by the coordinator. **darryn: replace or rewrite these
   in your own words.** Real sample lines from you are the strongest anchor.
9. **Open questions for darryn**: canon that isn't set yet. Nothing here is canon
   until darryn approves it; facts already in the game are marked *(in game)*.

All characters are adults (Prologue: Ryan ~22, Leia ~21, Julian ~23; present
day: Ryan 26, Leia 25, Julian 27; Maya is Ryan's age group, exact age TBD).
Everything sexual is between willing adults, and consent stays on the page.
