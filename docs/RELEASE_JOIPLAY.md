# JoiPlay release checklist (Android; not a native APK)

**Supported target:** JoiPlay 1.22.001 with **Ren'Py Plugin 8.5.3** (the JoiPlay 1.22 release announcement lists both). This matches the game's Ren'Py 8.5.3 SDK. Older plugins, including the 8.5.0 plugin, are not the supported target. The plugin supplies its own engine; do not assume a PC executable runs natively on Android.

## Each release

1. Start from the **same dedicated release worktree** and version/gate as the desktop demo, not the shared checkout. Preserve the Day One demo gate, release save-directory identifier and all release-only exclusions. In `game/options.rpy`, put exclusions for dev/QA scripts (`*.rpy*`), saves, cache, etc. **before** the `build.classify('game/**.rpy', 'joiplay')` line: first matching classification wins. Do **not** add the old unconditional `build.classify('game/**.rpy', None)` before that line; it would remove source from the JoiPlay package. The new `joiplay` file list sends `.rpy` to JoiPlay only; the normal PC/Mac packages continue to use `.rpyc` after compilation. Never release from an un-gated development checkout.
2. Run `PYTHONPATH=game/python-packages python -m unittest discover -s tests`, compile with the **8.5.3 SDK** (`<sdk>/lib/py3-windows-x86_64/python.exe <sdk>/renpy.py <release-worktree> compile`), then lint. Build with `<sdk>/lib/py3-windows-x86_64/python.exe <sdk>/renpy.py launcher distribute <release-worktree> --destination <output> --package joiplay --no-update` (from the SDK directory; system Python cannot import this SDK's pygame). Build PC/Mac separately as usual. The JoiPlay zip includes a Windows launcher for JoiPlay's **Add Game** picker, engine files, assets, `.rpy` sources and compiled `.rpyc`; it is **not** an APK and should not be uploaded as an Android APK or marked as a native Android build on itch.
3. Inspect the **actual zip**: a root executable next to `game/`, matching `.rpy` + `.rpyc` in `game/` (including late `zz*` overrides), all fonts/WEBP/OGG and `game/python-packages/lc_ui_logic.py`; no dev/QA sources or their `.rpyc`, and no **user saves or local cache artifacts** (Ren'Py itself generates `game/cache/build_info.json` and `game/cache/bytecode-312.rpyb` during packaging). Check the correct demo gate/version. Do not assume the Windows-only demo zip already published is enough: that build excluded `game/**.rpy`. Verify the ordinary PC/Mac archives still do **not** contain `.rpy`.
4. Upload the separate, accurately labelled **JoiPlay (Android, requires JoiPlay)** zip. Suggested itch/F95 line: **“Android: play via JoiPlay. Install JoiPlay and its Ren'Py 8.5.3 plugin, unzip the JoiPlay download, then add its main `.exe` in JoiPlay.”** Players need the whole extracted directory, particularly `game/`; they should not copy only `.exe` or only `.rpy`. Prefer one folder on internal storage with enough free space. Do not upload the zip as an itch browser/HTML build either.
5. Keep `config.save_directory` stable across updates, retain persistent data and save files, and warn that a different plugin/app or an upgraded game may not load older saves. Test fresh start, all three name prompts/keyboard, menu/choice scrolling and tapping, phone apps, load/save and persistent gallery, images, music/SFX and return to app from background on **an actual Android device** before claiming Android compatibility. Record device/Android/JoiPlay/plugin versions and any errors. Desktop lint/unit tests and zip inspection alone **cannot** verify mobile input, rendering, storage permissions, sound or memory use. No Android device test was performed in this change.

### Evidence versus risk

- **Documented:** JoiPlay's release post announces an 8.5.3 Ren'Py plugin; its website says to install both app and relevant plugin and to add a game using its executable. Ren'Py's build documentation specifies first-match file classification and custom `build.package` file lists. Ren'Py documents WEBP images, OGG/Opus audio and Android touch/input behavior. [JoiPlay release](https://www.patreon.com/joiplay/posts/joiplay-1-22-000-159457758) · [JoiPlay setup](https://joiplay.net/) · [Ren'Py distributions](https://www.renpy.org/doc/html/build.html) · [Ren'Py Android](https://www.renpy.org/doc/html/android.html) · [Ren'Py audio](https://www.renpy.org/doc/html/audio.html) · [Ren'Py images](https://www.renpy.org/doc/html/displayables.html)
- **Inference, not device-verified:** `.rpyc` compiled on 8.5.3 should load in a plugin running 8.5.3; sources are included so a separately configured compatible runtime can recompile if necessary. There is no promise that `.rpyc` from 8.5.3 works on an *older* 8.x engine. A native Python extension in `python-packages/` would need an Android-compatible build; none is currently tracked. The current game has no tracked movie, `.rpa`, Opus or native Python extension. The 1920×1080 GUI and large assets may affect phone memory/readability; a device check is required. JoiPlay's save/persistent locations are plugin-managed; do not prescribe a hard-coded Android save path without testing.
