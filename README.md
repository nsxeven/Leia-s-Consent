# Leia's Consent

Development repository for **Leia's Consent**, a choice-driven Ren'Py visual novel.

## Canon character defaults

- Leia — girlfriend / female lead
- Ryan — boyfriend / player POV
- Julian — friend / outside male influence

Players will be able to rename all three characters at the start of a new game. Internal code and asset identifiers will remain fixed for save and content stability.

## Development stack

- Ren'Py
- Visual Studio Code
- Git / GitHub Desktop
- ComfyUI

## Current milestone

Bootstrap the Ren'Py project, then build the relationship state engine and developer panel before beginning Chapter 1 production.
